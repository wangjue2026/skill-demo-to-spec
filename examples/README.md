## 案例深度剖析

### 1. 单模块样本：`sample-probe-config/`
- **说明书**：[`spec-01-监控配置中心.html`](./sample-probe-config/spec-01-监控配置中心.html)
- **数据契约**：[`types.ts`](./sample-probe-config/types.ts)
- **数据集**：[`mock-data.ts`](./sample-probe-config/mock-data.ts)
- **核心亮点**：
  - 纯内网离线自包含，零外网 CDN 脚本引用；
  - 顶部资产卡片（ZTNA 42、SaaS 86、自定义）与下表明细受控联动；
  - 完整呈现 Loading、Empty、Error、防重复提交状态机保护。
